# atendimento-bemtevi

O projeto que o leitor constrói ao longo de *O ciclo de vida de um agente*:
o agente de atendimento da Casa Bem-te-vi, uma loja online **inventada**.
Clientes, CPFs, e-mails, pedidos e transportadoras são todos falsos.

```bash
uv run pytest -q          # o contrato e as perguntas de referência estão válidos?
uv run python baseline.py # a nota de partida: quanto acerta quem passa tudo para um humano
```
